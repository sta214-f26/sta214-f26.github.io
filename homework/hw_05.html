Bootstrap confidence intervals for a regression coefficient

Previously

In class, we looked at creating a confidence interval for the difference in mean WBC between dengue and non-dengue patients. Here is the complete code from that class activity:

library(tidyverse)

# read in the dengue data
dengue <- read_csv("https://sta214-f26.github.io/homework/dengue.csv")

# estimated difference on the original data
mean_difference <- dengue |>
  summarize(mean_diff = mean(WBC[Dengue == 1]) - 
              mean(WBC[Dengue == 0])) |>
  as.numeric()

# desired number of bootstrap samples
n_boot = 1000

# create a vector in which to store the bootstrap samples
boot_ests <- rep(NA, n_boot)

# do the bootstrapping
for(i in 1:n_boot){
  # create a bootstrap sample 
  dengue_boot <- dengue |>
    sample_n(size = n(), replace=T)
  
  #re-calculate the difference in means
  # We will store the difference in the boot_ests vector
  boot_ests[i] <- dengue_boot |>
    summarize(mean_diff = mean(WBC[Dengue == 1]) - 
                          mean(WBC[Dengue == 0])) |>
    as.numeric()
}

# make a histogram of the results
hist(boot_ests)

# bootstrap percentile interval
quantile(boot_ests, c(0.025, 0.975))

# normal interval with bootstrap SE
mean_difference - 1.96*sd(boot_ests)
mean_difference + 1.96*sd(boot_ests)

Logistic regression

Now instead of looking at the difference in mean WBC between dengue and non-dengue patients, suppose we want to fit a logistic regression model. We decide to fit the following model:

\[ \begin{aligned} \text{Dengue}_i &\sim Bernoulli(\pi_i) \\ \log \left( \frac{\pi_i}{1 - \pi_i} \right) &= \beta_0 + \beta_1 \text{Age}_i + \beta_2 \text{WBC}_i + \beta_3 \text{PLT}_i \end{aligned} \]

Effect of Age

Our estimated coefficient on Age is \(\widehat{\beta}_1 = 0.138\). However, this estimate is based on a sample from the population, so will not be exactly equal to the true value of the parameter \(\beta_1\).

In addition to our point estimate \(\widehat{\beta}_1\), we would like an interval estimate that captures the amount of variability in \(\widehat{\beta}_1\) between samples.

A confidence interval provides a reasonable range of values for an unknown population parameter. The usual confidence interval for \(\beta_1\) in a logistic regression model looks like:

\[\widehat{\beta}_1 \pm z^* SE_{\widehat{\beta}_1}\]

where \(z^*\) is the critical value for our desired confidence level, and \(SE_{\widehat{\beta}_1}\) is the standard error of the estimated coefficient.

Let’s suppose we want to make a 95% confidence interval for \(\beta_1\); then \(z^* = 1.96\). However, we still need to get the standard error!

Another way of estimating standard error

Bootstrap resampling gives us a nice way to estimate standard errors. However, it requires us to write and run the bootstrapping code.

Rather than bootstrap, there are sometimes mathematical approximations to standard errors. For \(SE_{\widehat{\beta}}\), R actually reports these approximations by default!
