Data

Anxiety can affect musicians before performances, and can negatively affect their ability to play and their emotional state. In a 2010 study, researchers examined anxiety in 37 undergraduate music majors. For each musician, data was collected on anxiety levels before different performances (between 2 and 15 performances were measured for each musician). Each row in the data represents one performance; in this activity, we will work with the following variables:

  • id: a unique identifier for the musician
  • na: negative affect score (a measure of anxiety)
  • large: whether the musician was performing as part of a large ensemble (large = 1), or as part of a small ensemble or solo (large = 0)
  • audience: who attended (Instructor, Public, Students, or Juried)

The researchers hypothesize that, after accounting for audience type, students will be less anxious when performing in large ensembles. Furthermore, the researchers suspect that overall anxiety varies between individuals, but that the effects of ensemble size (large vs. small) and audience type are the same for each individual. They therefore write down the following mixed effects model:

\[ \begin{aligned} Anxiety_{ij} = \beta_0 + \beta_1 \ JuriedPerformance_{ij} + \beta_2 \ PublicPerformance_{ij} \\ \hspace{1cm} + \ \beta_3 \ StudentPerformance_{ij} + \beta_4 \ LargeEnsemble_{ij} + u_i + \varepsilon_{ij} \end{aligned} \]

\(u_i \overset{iid}{\sim} N(0, \sigma_u^2)\), \(\varepsilon_{ij} \overset{iid}{\sim} N(0, \sigma_\varepsilon^2)\)

Model diagnostics

Now let’s check assumptions for our fitted model.

One assumption our model is making is that the variance of the residual term \(\varepsilon_{ij}\) is the same for each student.

Inference

The researchers want to know if, after accounting for audience type, students will be less anxious when performing in large ensembles. This means that, for the mixed model above, we want to test

\[H_0: \beta_4 = 0 \hspace{1cm} H_A: \beta_4 < 0\]

One way to carry out this test is with parametric bootstrapping:

  • Calculate a test statistic on the observed data
  • Fit a reduced model (for which the null hypothesis is true)
  • Simulate data from the reduced model
  • Re-fit the model and re-compute the test statistic on the simulated data
  • Repeat many times

Fitting a reduced model

TipQuestion 7

Fit a reduced model (call it m0) for which the null hypothesis is true (no effect of ensemble size).

m0 <- lmer(na ~ ..., data = music)
summary(m0)

Simulating data from the reduced model

How do we simulate data from the reduced model? Remember that we combine predictions from the reduced model with new, simulated random effects and noise. For this data, a new anxiety score is given by

\[ \begin{aligned} Anxiety_{ij}^* = \widehat{\beta}_0 + \widehat{\beta}_1 \ JuriedPerformance_{ij} + \widehat{\beta}_2 \ PublicPerformance_{ij} \\ \hspace{1cm} + \ \widehat{\beta}_3 \ StudentPerformance_{ij} + u_i^* + \varepsilon_{ij}^* \end{aligned} \]

where \(u_i^* \sim N(0, \widehat{\sigma}_u^2)\) and \(\varepsilon_{ij}^* \sim N(0, \widehat{\sigma}_\varepsilon^2)\).

There are then three things we need to do:

  • Generate \(u_i^* \sim N(0, \widehat{\sigma}_u^2)\)
  • Generate \(\varepsilon_{ij}^* \sim N(0, \widehat{\sigma}_\varepsilon^2)\)
  • Calculate

\[\widehat{\beta}_0 + \widehat{\beta}_1 \ JuriedPerformance_{ij} + \widehat{\beta}_2 \ PublicPerformance_{ij} + \\ \ \widehat{\beta}_3 \ StudentPerformance_{ij}\]

TipQuestion 9

Fill in the code below to generate a new \(\varepsilon_{ij}^*\) for every performance in the data:

noise_new <- rnorm(n = ..., mean = 0, sd = ...)

Here n should be the total number of rows in the data, mean should be the mean of the normal distribution for \(\varepsilon\), and sd should be our estimate of the standard deviation \(\widehat{\sigma}_\varepsilon\).

Now we can put everything together to get our parametric bootstrap values \(Anxiety_{ij}^*\):

# predictions from fixed effects
fitted_values <- predict(m0, re.form = NA)

# simulated random effects
re_data <- data.frame(id = unique(music$id),
                        re = re_new) |>
    right_join(dplyr::select(music, id), by = "id")

# create parametric bootstrap data with the relevant variables
music_boot <- data.frame(id = music$id,
                         audience = music$audience,
                         large = music$large,
                         na = fitted_values + re_data$re + noise_new)
TipQuestion 10

Re-fit the full model on the parametric bootstrap data, and report the estimated coefficient \(\widehat{\beta}_4\):
