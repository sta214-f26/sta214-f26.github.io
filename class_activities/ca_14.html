Setup

In this activity, you will work with data on 400 applicants to graduate school. For each applicant, we have:

  • admit: whether they were admitted to a graduate program (0 = no, 1 = yes)
  • gre: their GRE score (out of 800)
  • gpa: their undergraduate GPA (out of 4.0)
  • rank: a proxy for school prestige (1 = most prestigious, 4 = least prestigious)

The data can be downloaded in R with:

grad_app <- read.csv("https://stats.idre.ucla.edu/stat/data/binary.csv")

Research question

We decide to use the logistic regression model

\[ \begin{aligned} \text{Admit}_i &\sim Bernoulli(\pi_i) \\ \log \left( \dfrac{\pi_i}{1 - \pi_i} \right) &= \beta_0 + \beta_1 \text{GPA}_i + \beta_2 \text{GRE}_i + \\ & \hspace{0.5cm} \beta_3 \text{Rank2}_i + \beta_4 \text{Rank3}_i + \beta_5 \text{Rank4}_i \end{aligned} \]

We fit the model in R:

m_full <- glm(admit ~ gpa + gre + as.factor(rank),
              family = binomial, data = grad_app)

Research question: Is there a relationship between GRE and grad school acceptance, after accounting for GPA and school rank?

Hypothesis testing

To answer this research question, we want to test the hypotheses

\[H_0: \beta_2 = 0 \hspace{1cm} H_A: \beta_2 \neq 0\]

Our test statistic is

\[Z = \frac{\widehat{\beta}_2 - 0}{SE_{\widehat{\beta}_2}}\]

Using the output of the fitted model above,

\[Z = \frac{0.002264}{0.001094} = 2.07\]

We then want to know: how unusual is this test statistic, if in fact the null hypothesis is actually true?

Parametric bootstrapping

To determine whether the observed value of \(Z\) is unusual under \(H_0\), we need the null distribution of our test statistic. We will use parametric bootstrapping to assess whether \(Z = 2.07\) is consistent with \(H_0\), or is unusual.

Step 1: Fit a model that assumes \(H_0\) is true

If \(H_0\) is true, then we don’t need \(\text{GRE}\) in the model

Step 3: Re-fit the full model with the simulated responses

Our simulated data (sim_data) now contains a response (admit_star) that is created to be unrelated to GRE score – that is, we have forced \(H_0\) to be true! To see how \(\widehat{\beta}_2\) and the test statistic \(Z\) behave in this situation, we need to re-fit the full model on this simulated data.

Step 5: Repeat many times!

We want a distribution for \(Z\) under \(H_0\), so we need to repeat many times. The following code will approximate the null distribution of \(Z\) with 5000 parametric bootstrap samples, and make a histogram:

nsim <- 5000
parametric_boot_stats <- rep(NA, nsim)

for(i in 1:nsim){
  admit_star <- rbinom(n = length(m_reduced$y),  
                       size = 1, 
                       p = m_reduced$fitted.values)
  
  sim_data <- grad_app |>
    mutate(admit_star = admit_star)
  
  m_full_sim <- glm(admit_star ~ gpa + gre + as.factor(rank),
                    family = binomial, data = sim_data)
  
  parametric_boot_stats[i] <- summary(m_full_sim)$coefficients[3, 3]
}

hist(parametric_boot_stats)

Step 6: Approximate a p-value

Finally, we will use the parametric bootstrap null distribution to approximate a p-value for our original test statistic.

Remember that a p-value measures the probability of a value “as or more extreme” as the observed test statistic. In our case, the alternative hypothesis is \(H_A: \beta_2 \neq 0\), so a value “as or more extreme” could be either \(> 2.07\) or \(< -2.07\).

In other words, we want \(P(|Z| > 2.07 \ | \ H_0)\).

TipQuestion 6

The following code will calculate the p-value:

mean(abs(parametric_boot_stats) > 2.07)

Report the p-value. Would you reject or fail to reject our null hypothesis \(H_0: \beta_2 = 0\)?
